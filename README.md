# FreeC Tier

> Проект находится в активной разработке.

**Виртуальная локальная сеть для игр и приложений — без собственного VPN-сервера.**

FreeC Tier позволяет объединить несколько компьютеров в одну виртуальную локальную сеть. После подключения компьютеры получают свои виртуальные IPv4-адреса и могут обращаться друг к другу так, будто находятся в одной домашней сети.

Это удобно для:

* игр по локальной сети;
* приложений, которым нужен LAN;
* TCP и UDP-соединений;
* `ping` и других сетевых инструментов.

> **FreeC Tier не является VPN для выхода в интернет.**
> Он не отправляет весь ваш интернет-трафик через другого пользователя и не меняет ваш обычный интернет-маршрут.

---

## Как это работает

FreeC Tier использует инфраструктуру **Steam Networking**, поэтому ему не нужен отдельный сервер FreeC Tier для передачи трафика между участниками.

Вам нужен только:

* Steam;
* запущенный клиент Steam;
* Windows 10 или Windows 11 x64.

Вы создаёте сеть, приглашаете друга через Steam — и после подключения ваши компьютеры оказываются в одной виртуальной LAN.

Пример:

```text
Ваш компьютер
10.77.1.1
     │
     │ Steam Networking
     ▼
10.77.1.2
Компьютер друга
```

После этого приложение или игра может использовать виртуальные IP-адреса участников.

---

## Подключение за несколько шагов

### 1. Запустите FreeC Tier

Откройте приложение на компьютере.

### 2. Создайте сеть

Нажмите **«Создать сеть»**.

FreeC Tier создаст виртуальную сеть и назначит вам адрес.

### 3. Пригласите друга

Выберите друга через Steam и отправьте ему приглашение.

### 4. Друг принимает приглашение

После принятия сети она появится у него в FreeC Tier.

### 5. Включите сеть

Оба участника включают виртуальную сеть.

### 6. Готово

Компьютеры получают виртуальные IP-адреса и могут обмениваться трафиком.

Например:

```text
Вы       → 10.77.1.1
Друг     → 10.77.1.2
```

Можно использовать этот адрес в игре или другом LAN-приложении.

---

## Нужно ли владельцу сети постоянно находиться в игре?

**Нет.**

Владелец нужен для изменения состава сети, но не должен постоянно находиться онлайн для обычного обмена трафиком между уже добавленными участниками.

Настройки сети сохраняются на компьютерах участников.

---

## Что важно знать

FreeC Tier сейчас находится в статусе **Preview 0.2**.

Основная концепция уже реализована, но проект всё ещё активно тестируется. Некоторые возможности пока могут работать неидеально.

На данный момент:

* поддерживается IPv4;
* работает TCP и UDP;
* используется виртуальный сетевой адаптер;
* собственного relay-сервера FreeC Tier нет;
* собственного signaling-сервера нет;
* автоматическая настройка Windows Firewall пока не реализована;
* полноценный тест между несколькими физическими компьютерами ещё продолжается;
* автоматический запуск вместе с Windows пока не реализован.

---

## Безопасность

Участники сети привязаны к своим аккаунтам Steam.

Каждому участнику назначается собственный виртуальный IP-адрес. Сеть подписывается владельцем, а клиент проверяет её перед использованием.

Это позволяет контролировать, кто входит в сеть и кто имеет право обмениваться трафиком.

Если участник удалён из сети, владелец может выпустить обновлённую конфигурацию без него.

---

## Требования

Для работы FreeC Tier требуется:

**Windows 10 / Windows 11 x64**

**Steam**

**Microsoft Edge WebView2 Runtime**

**Запущенный клиент Steam**

При запуске приложение может запросить права администратора Windows. Это необходимо текущей версии для управления виртуальным сетевым адаптером.

---

## Что FreeC Tier не делает

FreeC Tier не предназначен для:

* скрытия вашего IP в интернете;
* обхода ограничений всего интернет-соединения;
* отправки всего трафика через другой компьютер;
* замены обычного VPN.

Его задача намного проще:

> **создать виртуальную локальную сеть между вашими компьютерами.**
