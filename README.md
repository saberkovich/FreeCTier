# FreeC Tier

**FreeC Tier** — приложение для создания виртуальной локальной сети между компьютерами через инфраструктуру Steam.

По назначению это аналог **Radmin VPN / ZeroTier / Hamachi**, но вместо собственного VPN-сервера, центрального сервера или отдельной сети ретрансляторов используется **Steam Networking**.

> **Статус: Preview 0.2**
>
> Проект находится в разработке. Основная архитектура уже реализована, однако полноценная проверка работы между несколькими компьютерами ещё продолжается.

---

## Что можно делать

FreeC Tier позволяет объединить компьютеры пользователей в одну виртуальную IPv4-сеть.

Например:

```text
Компьютер A
10.77.x.1
     │
     │ Steam Networking
     │
     ▼
Компьютер B
10.77.x.2
```

После подключения компьютеры видят друг друга по виртуальным IP-адресам и могут использовать приложения, рассчитанные на работу в локальной сети.

В частности, проект ориентирован на:

* локальную игру по сети;
* Minecraft Java Edition;
* TCP и UDP-соединения;
* `ping`;
* приложения, которым требуется локальная IPv4-сеть;
* автоматическое обнаружение участников внутри виртуальной сети.

FreeC Tier **не является VPN для выхода в интернет**. Он не перенаправляет весь интернет-трафик через другого пользователя, не меняет DNS и не устанавливает маршрут по умолчанию.

---

## Почему Steam

Обычные программы вроде Radmin VPN создают собственную инфраструктуру для обнаружения пользователей и передачи трафика.

FreeC Tier использует для этого уже существующую инфраструктуру Steam.

Это позволяет отказаться от:

* собственного сервера FreeC Tier;
* отдельного relay-сервера;
* собственного signaling-сервера;
* отдельной системы аккаунтов;
* ручной настройки портов.

Для работы нужен обычный аккаунт Steam и запущенный клиент Steam.

При этом FreeC Tier не создаёт отдельное подключение к серверу FreeC Tier — такого сервера в архитектуре проекта нет.

---

## Как это работает

Каждая виртуальная сеть имеет владельца и список участников.

Участникам выдаются постоянные виртуальные IPv4-адреса, например:

```text
10.77.1.1
10.77.1.2
10.77.1.3
```

SteamID пользователя связывается с его виртуальным IP.

Конфигурация сети подписывается ключом владельца. Благодаря этому клиент может проверить, что полученная конфигурация действительно создана владельцем сети и не была изменена участником.

Передача пакетов происходит через **Steam Networking Sockets**.

В текущей версии ICE отключён:

```text
P2PTransportICEEnable=0
```

То есть проект рассчитан на использование Steam Networking / SDR-маршрута без собственного fallback-транспорта.

---

## Создание сети

На компьютере владельца:

1. Запустите FreeC Tier.
2. Создайте новую сеть.
3. Пригласите друга через Steam.
4. Друг принимает приглашение.
5. Оба участника включают виртуальный адаптер.
6. FreeC Tier назначает компьютерам виртуальные IP-адреса.
7. После этого компьютеры могут обмениваться трафиком внутри сети.

В дальнейшем сохранённая сеть остаётся на компьютерах участников.

Владелец нужен для изменения состава сети, но не должен постоянно находиться в сети для обычного обмена трафиком между уже добавленными участниками.

---

## Сохранение сети

FreeC Tier сохраняет информацию о сети локально.

Если владелец удалит сохранённую сеть со своего компьютера, другие участники не потеряют свои копии.

Однако для восстановления управления сетью владельцу потребуется резервная копия её JSON-конфигурации.

---

## Безопасность

FreeC Tier использует несколько уровней защиты.

### SteamID

Подключение связывается с идентификатором пользователя Steam.

### Подпись конфигурации

Конфигурация сети подписывается ключом владельца с использованием **Ed25519**.

Клиент проверяет подпись перед сохранением и активацией конфигурации.

### Фиксированные IP

Виртуальный IP привязан к конкретному SteamID.

Участник не может самостоятельно назначить себе чужой адрес.

### Проверка пакетов

Полученный пакет должен:

* принадлежать активному участнику сети;
* использовать назначенный ему исходный IP;
* относиться к текущей виртуальной сети.

### Отзыв доступа

Владелец может выпустить новую версию конфигурации без удалённого участника.

После получения обновлённой конфигурации остальные клиенты перестают принимать трафик от отозванного участника.

## Что находится внутри

Проект состоит из нескольких частей:

```text
FreeC Tier
├── Rust core
│   └── Сетевая логика
│
├── Tauri 2
│   └── Desktop-приложение
│
├── Wintun
│   └── Виртуальный сетевой адаптер
│
├── Steam Networking
│   └── Передача P2P-трафика
│
└── CLI
    └── Диагностика и тестирование
```

Виртуальная сеть создаётся через **Wintun**.

В текущей версии используется:

* Windows 10/11 x64;
* IPv4;
* MTU 1280;
* TCP;
* UDP;
* ICMP;
* broadcast;
* ограниченная multicast-поддержка для обнаружения Minecraft Java.

---

## Minecraft

Одна из основных целей проекта — возможность запускать игры так, будто компьютеры находятся в одной локальной сети.

Для Minecraft Java Edition реализована обработка трафика, необходимого для LAN-обнаружения:

```text
224.0.2.60
```

Также обрабатываются:

```text
255.255.255.255
```

и subnet broadcast.

Однако полноценное Minecraft LAN-обнаружение ещё требует дополнительной проверки на реальных нескольких компьютерах.

## Требования

Для запуска:

* Windows 10 или Windows 11 x64;
* Steam;
* Microsoft Edge WebView2 Runtime;
* запущенный клиент Steam.

Для сборки:

* Rust 1.90+;
* MSVC toolchain;
* Node.js 20.19+ или 22.12+;
* npm;
* Visual Studio Build Tools;
* компонент **Desktop development with C++**;
* Windows SDK.

Steamworks SDK вручную устанавливать не требуется.

Сборочная система автоматически подготавливает необходимые файлы Steamworks.

## Сборка

Самый простой способ — запустить:

```bat
build.bat
```

Скрипт автоматически:

1. устанавливает необходимые зависимости;
2. подготавливает Steamworks;
3. загружает Wintun;
4. проверяет SHA-256 Wintun;
5. собирает frontend;
6. собирает Rust-приложения;
7. формирует готовую папку.

Результат:

```text
dist/
└── FreeC-Tier-release/
    ├── freec-tier.exe
    ├── freec-runtime.exe
    ├── steam_api64.dll
    ├── wintun.dll
    ├── WINTUN-LICENSE.txt
    └── README.md
```

Запускайте:

```text
freec-tier.exe
```

из этой папки.

Обе DLL должны находиться рядом с исполняемыми файлами.

### Варианты сборки

```bat
build.bat
```

Обычная release-сборка.

```bat
build.bat --debug
```

Быстрая debug-сборка.

```bat
build.bat --no-pause
```

Сборка без остановки консоли в конце. Удобно для CI.

## Права администратора

FreeC Tier сейчас управляет Wintun непосредственно из desktop-приложения.

Поэтому при запуске готового EXE Windows может показать запрос UAC.

Это необходимо для работы виртуального сетевого адаптера.

Если пользователь отклоняет запрос, приложение не сможет запустить текущую сетевую часть.

В дальнейшем планируется вынести привилегированную часть в отдельную Windows-службу. Это позволит сделать архитектуру безопаснее и подготовить проект к полноценному публичному релизу.

---

## Текущие ограничения

FreeC Tier пока является **Preview**, поэтому некоторые функции ещё находятся в разработке.

Сейчас:

* поддерживается только IPv4;
* нет собственного relay-сервера;
* нет собственного signaling-сервера;
* нет fallback-транспорта;
* нет полноценного публичного установщика;
* нет отдельной Windows-службы;
* автоматическая настройка Windows Firewall ещё не реализована;
* трёхкомпьютерный тест ещё не завершён;
* Minecraft LAN discovery требует дополнительной проверки;
* обнаружение конфликтов маршрутов ещё находится в разработке;
* rate limiting discovery-трафика ещё не реализован;
* автоматический запуск вместе с Windows ещё не реализован.

## Обновления

FreeC Tier поддерживает проверку подписанных обновлений.

Для этого используется подпись Tauri updater.

Ключ подписи должен храниться отдельно от исходного кода.

Обновление проверяет подпись перед запуском установщика.

Поддерживается публикация релизов через GitHub Actions.

## Важный момент

FreeC Tier не пытается заменить Steam или создать собственную интернет-инфраструктуру.

Идея проекта проще:

> **создать виртуальную LAN поверх Steam Networking.**

Пользователи продолжают использовать свои Steam-аккаунты, а FreeC Tier превращает соединение между ними в обычную виртуальную IPv4-сеть, с которой могут работать игры и другие LAN-приложения.
