**FreeC Tier** - приложение для создания виртуальной локальной сети между компьютерами через инфраструктуру Steam.

Подключайте друзей и устройства так, будто они находятся в одной локальной сети — без собственного VPN-сервера, ручной настройки портов и проброса NAT.

**Возможности:**
* 🌐 Виртуальная IPv4-сеть между участниками
* 🎮 Использование Steam Networking для передачи данных
* 🔒 Соединение без собственного центрального VPN-сервера
* ⚡ Автоматическое установление соединения
* 🖥️ Поддержка Windows 10 и Windows 11 x64
* 🦀 Написан на Rust
* 📦 Минимум ручной настройки

FreeC Tier подходит для игр по локальной сети, тестирования сетевых приложений и других сценариев, где компьютерам нужно видеть друг друга как устройства одной LAN.

> **Проект находится в разработке**. Текущая версия является прототипом, поэтому некоторые функции и поведение сети могут измениться.
